# Md. Abrar Faiyaj — Personal Research Portfolio

Static, single-page research portfolio website.

## Deploy on GitHub Pages

1. Create a GitHub repository named `mdabrarfaiyaj.github.io` (replace with the exact username if different).
2. Upload `index.html` and `.nojekyll` to the repository root on the `main` branch.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and Save.
4. Visit `https://mdabrarfaiyaj.github.io/` after deployment.

## Notes

- Image and certificate assets are embedded as data URIs in `index.html` to simplify deployment.
- Review all personal/public details and evidence documents before publishing.
- Edit `index.html` to update the portfolio.
